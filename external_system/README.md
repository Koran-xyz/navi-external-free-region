# 外部システム領域｜AIチーム共同会議基盤 v0.1

## 目的

AI同士を直接つなぐのではなく、各AIチームが同じ外部作業空間へ参加できる共通基盤を作る。

ユーザー → ナビィ → 外部作業空間 → 各AIチーム → アドミン整理 → ナビィ → ユーザー

## 役割

- ナビィ: ユーザーと外部作業空間の伝達役。依頼を議題化し、結果を返す。
- アドミン: 会議進行・調整役。参加チーム、発言順、再質問、終了判定を整理する。
- 各AIチーム: 自分の内部構成で検討し、チーム回答を外部作業空間へ提出する。

## 現在のチーム

- ゴテンチーム: ゴテン + 他0 = 1体
- マリア助手チーム: マリア助手 + 他4エージェント = 5体
- エデンチーム: エデン + 他4エージェント = 5体

合計11エージェント。

## 会議モード

### 統合モード
各チームが回答し、アドミンが論点を整理。ナビィが1つの統合結果としてユーザーへ返す。

### 並列モード
ゴテンチーム、マリア助手チーム、エデンチームの回答を3本そのままユーザーへ返す。

## 外部サービスの役割

- Notion: 決定・保留・現在地・復元情報・索引の正本
- Googleドキュメント: 自由な会議ログ・バトンリレー・途中議論
- GitHub: チーム定義、会議規格、JSON、実装コード、更新履歴

## 最小データ

会議ID / ユーザー依頼 / 会議モード / 参加チーム / 状態 / 各チーム回答 / アドミン整理 / 最終結果 / 次の作業

## 方針

各AIの接続方法は統一しない。API、MCP、ブラウザ操作、手動バトンなどの違いは外部接続層で吸収し、外部作業空間上では同じ会議参加者として扱う。
