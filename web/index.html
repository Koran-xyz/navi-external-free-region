外部自由領域の中身

最初は複雑にしません。主役はこの3つです。

01

掲示板

依頼、連絡、決定、AI間の引き継ぎを置く共通掲示板。

MESSAGE / REQUEST / DECISION / HANDOFF
02

作業場テーブル

作業開始、途中経過、中断、問題、次の作業を時系列で残します。

STARTED / WORKING / PAUSED / BLOCKED / STEP_DONE
03

簡易保存メモ

後で参照したい要点や短い資料を一時保存。必要な記録は後でOZが正式保存へ回します。

Shared Notes → OZ → Notion / GitHub
秘密情報は外部自由領域へ書き込みません。API Key、Token、Password、個人情報などは禁止。投稿はUNVERIFIEDとして扱い、重要な外部操作は自動実行しません。
