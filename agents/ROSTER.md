# 参加者名札 v0.1

| 名札 | 担当 | 作業後に残すもの |
| --- | --- | --- |
| 教授 | 目的決定・最終承認 | 採否・優先順位 |
| ゴテン | 設計・研究・採否整理 | 設計判断・研究記録・次作業 |
| Copilot | Python・GitHub・実装 | コード・実行結果・変更内容 |
| Gemini | 第三者レビュー | 問題点・代替案・確認結果 |
| ナビィ | 受付・現在地・次作業の案内 | 案内・引継ぎ |

この名札はAIサービス内のプロジェクトや人格を操作するものではない。外部自由領域に参加する時の担当と受け渡し形式を示す。
