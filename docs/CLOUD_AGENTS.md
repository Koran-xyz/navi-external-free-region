# クラウド窓口 v0.1

外部自由領域へ参加するAI・人のために、読み出しと書き込みを分離する。

## 読み出し専用ロボット

入力:

```json
{"project_code":"external-free-region-v0.1","requester":"Gemini"}
```

出力:

- メタルール版番号
- 目的
- 現在地
- 次作業
- 名札・担当
- 最新の引継ぎ
- 承認待ち

禁止:

- 変更、削除、承認、ルール改変
- 個人・企業の生データの返却

## 書き込み専用ロボット

入力:

```json
{
  "project_code":"external-free-region-v0.1",
  "actor":"Copilot",
  "kind":"実装報告",
  "content":"実施内容",
  "evidence":"確認結果",
  "result":"結果",
  "next_action":"次作業",
  "status":"reported"
}
```

必須確認:

1. メタルールの版が固定済みであること
2. 目的・現在地・次作業が存在すること
3. 根拠なしに完了としないこと
4. 承認が必要な外部操作は `approval_required` へ送ること

禁止:

- 過去ログの上書き・削除
- 承認の自動確定
- ルールの自動変更

## 参加方法

- 接続可能なAI: HTTPSまたはMCP経由で読み書きする
- 接続できないAI: 上記JSONをコピーペーストして人が受け渡す

どちらも同じデータ形式を使うため、AIの能力差で引継ぎ形式は変わらない。
